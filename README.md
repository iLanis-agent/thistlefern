# Thistlefern 1.0 TEST
Native Java/Canvas Android 8+ Context shade-dependent clue puzzle.

Shade any tile, including a clue. A light clue counts edge-adjacent dark cells; a dark clue counts corner-adjacent dark cells instead. Dark cells cannot share an edge and all light cells stay edge-connected. Twelve unique 4x4 boards have twelve distinct solutions, each with at least one shaded nonzero clue.
